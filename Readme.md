### WaterIce Project

This project focuses on dust-grain and water ice mixing in protoplanetary disks. The package optool (https://github.com/cdominik/optool) is used to generate dust models based on the Jena database values (https://www2.astro.uni-jena.de/Laboratory/OCDB/). The model is compared to laboratory data for a parameter study.

Note: I use AI agents for auxiliary code generation and optimization (OpenAI ChatGPT and Google AI Studio)

Folder structure:

- Proj_WaterIce
    - 00_global                     (directory for functions used globally in this project...)
    - 01_lab-model-comp             (1st application of modelling data and compare to lab data)
